# Herdr coordination

Use only when explicitly asked to delegate. Read README.md and `python3 <skill-dir>/coord.py --help`. Use a live local parent, unique domain/task and dedicated existing checkout. Preview first; authorize the exact report directory and bounded source scope. Start at most three live workers; no nested agents absent explicit authorization. Never bypass trust, sandbox or approval decisions.

Default workers report through the designated local artifact, not hc, socket or network. No broad network or Herdr access is granted. A sandbox denial is a blocker, not permission to escalate. Parent runs `wait` then `collect` (or just `collect`); hc news may wake wait, but the file itself does not. A report is an unverified worker claim, not approval or proof. Verify independently. Launch does not prove prompt consumption. Never retry uncertain launches or sends without inspecting and reconciling first. No forced sends, background watchers, automatic starts, pushes, merges or cleanup.
